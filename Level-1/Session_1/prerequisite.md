# JavaScript Session -- Setup Instructions

Before attending the session, please follow these steps to prepare your
environment and make sure you can run TypeScript code.

## 1. Visual Studio Code

Download VS Code from: https://code.visualstudio.com/download

- Download the version suitable for your operating system.
- Run the installer and follow the installation steps.
- Keep the default settings.

## 2. Node.js

Download Node.js from: https://nodejs.org/en/download/

- Choose the **LTS** version.
- If you're using Windows, download the Windows Installer (`.msi`).
- Run the installer and keep the default settings.

## 3. Verify Installation

Open VS Code → **Terminal** → **New Terminal**.

Run these commands one at a time:

```bash
node -v
npm -v
```

If both commands return a version number, you're ready!

## 4. Run Your First JavaScript File

1. Create a folder.
2. Open the folder in VS Code (**File → Open Folder**).
3. Create a file named `main.js`.
4. Write the following code:

```javascript
console.log("Hello JavaScript!");
```

5. Open the terminal in VS Code and run:

```bash
node main.js
```

If you see `Hello JavaScript!` in the terminal, everything is working correctly.

Now you're ready for the session!
